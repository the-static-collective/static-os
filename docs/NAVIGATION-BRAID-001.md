It records only:\n\n- the digest of the base history;\n- the shared admitted parent-cycle digest;\n- the shared root-cycle digest;\n- a canonical branch-set digest;\n- content-addressed branch artifacts.\n\nBranch verification delegates the parent continuity question back to the existing history verifier.\n\n## Bounded branch capsules\n\nEach static.navigation-branch-capsule/v0 has exactly ten fields:\n\nschema\nbranch_id\nparent_cycle_digest\nroot_cycle_digest\nfrom_heading\nadmitted_heading\ntrace_ledger_sha256\ntransition_sha256\nreorientation_sha256\nadmission_sha256\n\nNo capsule descriptors:\n\nbranch_id\nbranch_digest\nadmitted_heading\n\nDescriptors are sorted by branch digest for canonical serialization.\n\nThat ordering is not a ranking.\n\nThe verifier explicitly reports branch_ranking_claimed = false.\n\n## Plurality requirements\n\nA valid first braid requires at least two branches.\n\nEvery branch must:\n\n- descend from the same admitted parent cycle;\n- preserve the same root history;\n- start from the parent's admitted heading;\n- carry a separately verified Dogram trace;\n- carry a valid proposed transition;\n- carry a matching NAV reorientation;\n- carry reorientation, and admission material are present and consistent with the verified base spine.\n\nincomplete:\nRequired witness material for a declared branch is absent. This does not prove the branch never existed.\n\ninvalid:\nPresent material contradicts the braid, for example a stale digest, wrong parent, duplicate heading, mutated transition, or undeclared hidden branch.\n\n## Hostile controls\n\nThe test suite requires:\n\n1. two branches verify complete;\n2. both branches share the same parent cycle;\n3. both branches share the same root history;\n4. admitted headings remain distinct;\n5. branching leaves the base spine byte-for-byte unchanged;\n6. branch capsules stay fixed-shape;\n7. duplicate headings are refused as collapsed plurality;\n8. a branch from a different admitted parent is refused;\n9. missing branch witness material yields incomplete;\n10. mutated addressed material yields invalid;\n11. undeclared hidden branches yield invalid;\n12. branch descriptors are canonical but unranked;\n13. a branch set cannot mix different parent spines.\n\n## Why this matters\n\nA linear navigator can preserve where it came from.\n\nA plural navigator must additionally preserve that more than one lawful continuation was available at the same historical point.\n\nIf only one branch survives in memory, the runtime quietly rewrites possibility as inevitability.\n\nThe braid preserves the stronger fact:\n\nTHE ROAD TAKEN DOES NOT ERASE THE ROADS THAT WERE LAWFULLY AVAILABLE.\n\n## Claim limit\n\nThis slice receipts plural admitted navigation possibilities. It does not rank them, merge them, prove either branch correct, or establish external causal history from graph topology.\n\n## Next pressure\n\nThe natural next test is branch continuation and convergence.\n\nCan one branch continue linearly while another remains open, and can a later composition refer to both without erasing which edge was spine continuation and which edge was branch relation?\n\nThat is the navigation analogue of Dogram's LINEAGE-WEAVE problem:\n\nCOMPOSITION MUST PRESERVE THE GRAMMAR OF THE CROSSING, NOT JUST THE RESULT.
