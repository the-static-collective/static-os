# V1

V1 is the first named whole-world cut of the distributed-ish, analogue-ish, AI-ish crank futureworld.

It is not one computer, one cloud, one agent, or one transport.

It is a field of strange particulars that can perform bounded work, carry artifacts through incompatible substrates, die, reappear, and still preserve what happened.

## V1 thesis

> THE WORLD IS THE BUS.

Anything that can preserve a bounded symbol can potentially become a carrier without becoming authority.

## The V1 organs

### CRANK

One explicit physical or logical turn authorizes at most one bounded work attempt.

    TURN != LOOP

### MODEL CARTRIDGE

AI is a replaceable organ behind a stable proposal contract.

    MODEL != MACHINE
    MODEL != MEMORY
    MODEL != OPERATOR
    INFERENCE != DECISION

### WORLD BUS

Carrier diversity is deliberate:

- ordinary network
- USB / SD
- QR / print
- NFC
- Bluetooth / LoRa / radio
- serial
- audio modem
- webZ
- human courier

    TRANSPORT != TRUST
    CARRIER != AUTHORITY

### PAPER BOOTLOADER

A machine should be able to carry enough printed/public recovery material to rediscover its ancestry, expected software, keys/pins, manifests, and reconstruction instructions without treating paper as canonical state.

    PAPER != LOSSY FALLBACK
    RECOVERY INSTRUCTION != CURRENT STATE

### CLOCKWORK COMPUTE FIELD

Machines advertise bounded useful capabilities. Work can travel until a capable node elects to perform one piece.

No central scheduler is required by the architecture.

    AVAILABLE != SELECTED
    SELECTED != EXECUTED
    EXECUTED != ACCEPTED

### SLOW INTERNET

Latency can be hours or days. A crossing can ride a bicycle or sit on a shelf without becoming failed merely because no process remains connected.

    DELAY != FAILURE
    OFFLINE != DEAD

### MECHANICAL BUDGET

Mechanical motion, measured power, storage, compute, or bandwidth may contribute resource evidence without becoming semantic authority.

    ENERGY != AUTHORITY
    RESOURCE CLAIM != PROOF

### GHOST MACHINES

Nodes may die. Their descendants may reconstruct lineage without inheriting the predecessor's identity or authority.

    CONTINUITY != IMMORTALITY
    ANCESTRY != AUTHORITY

### BOILER ROOM

The physical console is a debugger, not theater pasted over software:

- crank -> TURN
- selector -> capability choice
- gauge -> unresolved/held state
- bell -> RETURN
- thermal printer -> carrier / receipt
- lever -> locally authorized disposition surface
- patch cable -> declared transport aperture

Every physical control must terminate in a named software primitive.

## VEHICLE ECM

A vehicle joins V1 as another sovereign physical machine, but the initial aperture is deliberately narrow.

V1 accepts **authorized, already-collected read-only observations** from a local vehicle diagnostic adapter and turns them into content-addressed receipts.

Founding allowlisted observation classes include ordinary non-control telemetry such as:

- engine RPM
- vehicle speed
- coolant temperature
- battery voltage
- fuel level
- intake air temperature
- reported diagnostic trouble-code tokens

The founding V1 adapter does **not** transmit diagnostic commands or expose actuation/reprogramming machinery.

    VEHICLE TELEMETRY != VEHICLE CONTROL
    BUS ACCESS != ACTUATION AUTHORITY
    DIAGNOSTIC ADDRESSABILITY != PERMISSION
    OBSERVATION != COMMAND
    ECM != DRIVER AUTHORITY
    SAFETY-CRITICAL WRITE != V1

The useful weirdness is still substantial: a parked vehicle can become a locally witnessed sensor/energy/mobility particular in the field without V1 pretending it owns the vehicle.

Examples of later safe research directions include combining separately measured location, weather, electrical, maintenance, or journey artifacts at the receipt layer while preserving which device actually observed each fact.

## V1 constitutional boundary

V1 is failing if any convenience layer quietly collapses these distinctions:

    OBSERVATION != COMMAND
    PROPOSAL != DECISION
    WORK != AUTHORITY
    TRANSPORT != TRUST
    CROSSING != ADMISSION
    ENERGY != AUTHORITY
    NODE != NETWORK
    MODEL != OPERATOR
    CONTINUITY != CENTRAL SERVICE

V1 should become stranger by adding new particulars, not by weakening those boundaries.
