## What changes

The default Workbench surface becomes **GHoT — Giant Heap of Things**.

GHoT presents the existing habitat as an idle-clicker/RPG control board:

- local observed counts become resources;
- operator roles become party members;
- existing Workbench desks become quests;
- explicit human boundaries become boss gates;
- the local Workbench journal count becomes witness XP;
- one idle tick refreshes bounded observational projections.

The game shell routes into existing desks rather than implementing alternate hidden authority.

## Evidence gates

STATIC OS CI must fetch the exact pinned Workbench commit and run its host-level UI tests and JavaScript syntax check.

Passing those gates proves only that the pinned candidate can be fetched and that its existing host-level tests pass.

It does not prove:

- booted ISO operation;
- hardware installation;
- scheduled autonomous execution;
- external Polsia operation;
- real economic-resource accounting;
- safe possession of third-party credentials;
- unattended publication or deployment.

Those remain later gates.
