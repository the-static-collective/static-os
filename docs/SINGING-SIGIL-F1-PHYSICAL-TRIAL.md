## What exists now

An original experiment-specific, audible **DTMF telephone-keypad signal** and a
standard QR coupon are deterministically generated by the tool. They both
represent the *same literal plain-text payload*:

    SCF1:SS001:1E49EDB6

This includes protocol prefix \`SCF1\`, the bounded lab ID \`SS001\`, and an
eight-digit CRC32 of \`SCF1:SS001\`. CRC32 checks accidental corruption **only**.
It is not a signature, publisher identity, authorization, stable public
address, or recording ID.

The generator creates:
- 48-kHz 16-bit PCM mono WAV: two identical 16-key DTMF transmissions, with
  100-ms keypad tones and 40-ms gaps; 500-ms quiet lead and 700-ms repeat gap.
- Standards-readable QR PNG and SVG with a **four-module quiet zone**.
  QR generation needs the optional \`qrcode[pil]\` Python package.
- Sidecar JSON declaring the short ID reference to
  \`artifact:singing-sigil-companion-001\`, the original WAV hash, no execution.
- A raw text payload for other QR generators.
- A WAV decoder that checks DTMF symbols + CRC32; emits
  \`CANDIDATE_ONLY\` or \`NO_VALID_PACKET\`. Never runs arbitrary code or
  opens URLs, and never equates a digital decode with physical witness.

**Not done:** printing on actual paper, any QR scan by a human device, any
speaker-to-air-to-microphone decoding, Bandcamp album mutation, source track
authentication, two-device conversation, human consent, or deployment.

No existing The Static Collective recording is modified. It is a standalone
lab coupon, not an acoustic watermark in a pre-existing master.

## Reproduce without cloud services

From a Python 3.10+ checkout:

    python3 scripts/singing_sigil_f1.py make --out coupon
    python3 scripts/singing_sigil_f1.py decode coupon/singing-sigil-f1-dtmf.wav
    python3 -m unittest -v tests/test_singing_sigil_f1.py

For QR asset generation, first install the optional package in a local virtual
environment:

    python3 -m pip install 'qrcode[pil]'

Without that package, source WAV, manifest and payload text remain available.
The decoder uses only the Python standard library and supports mono
16-bit PCM WAV at sample rates from 8 to 96 kHz. Compressed AAC/M4A recordings
are not directly supported, and uncontrolled device DSP may impair decoding.

## Human physical trial protocol

1. Print the generated QR at a readable size (e.g. 5 cm across including the
   white margin), **without cropping the quiet zone**, or display the PNG on a
   second screen. Scan with a camera and record the exact observed text.
2. Play the separate WAV on a **speaker**, gently and at comfortable volume.
   Record the audible signal **in air on a second device**; do not connect
   unknown electrical wiring or speakers directly.
3. Retain the original mic capture unchanged. If necessary export a copy to
   mono PCM 16-bit WAV for decoding. Hash the actual capture bytes
   independently. Do not call a transcoded file the same original.
4. Decode the captured WAV with the script. A valid payload matching the QR
   is a decoder candidate; no automatic action follows.
5. Run **20 QR attempts and 20 audible attempts**, including misses, false
   positives, changes in distance/lighting/noise, and repeated exposures.
   Record each trial in the CSV. Missing results stay UNRUN, not PASS.
6. Only after independent successful observations should the existing
   FIELD-SCORE observation layer be extended with native
   \`capture_kind=PHYSICAL\` records. The current synthetic adapter expressly
   refuses physical inputs, and this tool does NOT bypass that guard.

The fixed text in the WAV is not a site URL and must never trigger a network
request or application launch.

## Test limitations and expected counterexamples

- Digital WAV generation and decoding may round-trip perfectly while a phone
  suppresses DTMF via noise reduction or automatic gain control.
- Mono16 WAV is required by this first bounded decoder; stereo and lossy
  phone recordings need a separately declared conversion history.
- Two readings of the same WAV do not prove two independent sources.
- Playback and scan times in disconnected devices are not globally ordered.
- Old QR or DTMF payloads can be replayed; the short ID has no secure nonce.
- A DTMF tone is deliberately audible, not hidden, ultrasonic, or presumed
  robust against Bandcamp transcodes.
- A matching CRC proves no producer/publisher permission or content truth.
