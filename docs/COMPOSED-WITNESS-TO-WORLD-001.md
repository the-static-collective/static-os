## Why measurement independence stays unknown

The current provenance shows why the experiment happened.

It does not, by itself, fully establish whether the measurement channel, operator, sensor, external source, or capture conditions were independent of the orienting history.

That requires a separate audit.

So WORLD refuses both of these unsupported moves:

```
fresh observation → independent measurement
```

and:

```
oriented experiment → measurement necessarily dependent
```

Instead:

```
selection dependence = known
measurement independence = unknown
```

## Hostile controls

The tests require that:

1. fresh contact is new but does not count as independent confirmation;
2. typed orientation ancestry survives intact;
3. fresh source and orienting generation have different hashes;
4. freshness cannot upgrade measurement independence;
5. selection independence cannot be claimed;
6. relation-kind collapse is refused;
7. unknown measurement independence cannot count as confirmation;
8. WORLD claim limits remain explicit;
9. inspection keeps all epistemic axes separate;
10. mutated WITNESS provenance is refused;
11. the next door requires a separate independence audit;
12. source observation text remains free of provenance graph material.
