# NAV — POCKET CARD

**Invariant:** ORIENTATION PRECEDES FORCE.

**Carry line:** THE LOOP MUST BE SURPRISED.

1. Name the heading.
2. Protect what matters.
3. Open one aperture.
4. Make one bounded move.
5. Let consequence answer.
6. Record the delta.
7. Reorient.

## Stop rule

If nothing outside the loop is allowed to change the next move, you are not navigating yet.

## Receipt

Record:

- heading
- preserve set
- aperture
- bounded move
- stop condition
- observed result
- delta
- next heading
- claim limit

A receipt is a path trace, not a score.
